# 3D-Portfolio

> An immersive, interactive 3D retro portfolio website built with Three.js, WebGL, React, and TypeScript. Featuring an isometric 3D developer desk with a CRT monitor running a nostalgic Windows 98-inspired OS.

## 🚀 Features

- **3D Room & Interactive Desk:** Realistic CRT monitor, mechanical keyboard, mouse, room lighting, dynamic shadows, and coffee steam.
- **Retro Desktop OS (Windows 98 Style):** Interactive windows, draggable dialogs, taskbar, start menu, and desktop shortcuts.
- **Showcase Explorer:**
  - **About Me:** Biography, MCA & BCA education details, and tech interests.
  - **Experience:** Java Developer Internship at Tap Academy, hackathons, and certifications.
  - **Software Projects:** AI-Enhanced E-Commerce Platform, AI-Assisted Food Delivery Application, and 3D Portfolio.
  - **Resume Download:** Built-in PDF resume download.
  - **Contact:** Interactive contact form, email, and social profiles.
- **Classic Retro Games:** Playable DOOM, The Oregon Trail, Scrabble, Wordle, and interactive shutdown sequence.
- **Spatial Audio:** Mechanical keyboard clicks, mouse clicks, computer fan ambience, startup sound, and retro radio tunes.

## 🛠️ Tech Stack

- **3D Scene:** Three.js, WebGL, GLSL Shaders, CameraControls, GSAP
- **Desktop OS:** React 17, TypeScript, Framer Motion, CSS3DRenderer
- **Build Tools:** Webpack 5, Babel

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Brajesh2244/3D-Portfolio.git
cd 3D-Portfolio
```

### 2. Install dependencies
```bash
npm install --legacy-peer-deps
npm --prefix inner-site install --legacy-peer-deps
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build:all
npm start
```
